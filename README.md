# 📊 Sales Data Dashboard

This project presents a Sales Data Dashboard built for analyzing product sales performance across teams, categories, and regions. The dashboard provides both tabular and visual insights using Power BI/Excel/any BI tool.

## 📁 Project Structure

- `Dashboard.jpg`: Screenshot of the Sales Data Dashboard.
- `insights.txt`: File containing 3–4 key insights derived from the dashboard.
- `README.md`: Overview of the project, features, and insights.

## 📌 Key Features

- Interactive data table showing geo-wise product sales.
- Bar and pie charts illustrating:
  - Sum of sales amount by team and product category.
  - Equal geographic data distribution.
- Stacked bar visual showing quarterly trends in box sales across teams and categories.
- Integrated map highlighting geo distribution of sales.

## 🔍 Insights Derived

1. **High Sales Contribution from Bars Category**  
   The "Bars" category dominates across all teams, especially Delish and Juicies, with the highest sales amount.

2. **Geographic Distribution is Even**  
   All five regions (Australia, Canada, India, New Zealand, and one unidentified region) have an equal number of entries — 670 records each (17%).

3. **Quarterly Sales Trend is Consistent**  
   Box sales remain consistent across Q1 to Q4, with Delish and Juicies consistently leading each quarter.

4. **Australia - Key Contributor in the Sampled Data**  
   The sample data highlights Australia (under Delish team) as a major revenue source, with several high-value sales.
